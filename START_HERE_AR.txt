NEXUS PREMIUM STORE — دليل التشغيل السريع (Windows)
====================================================

1) فك ضغط الملف في مجلد جديد. احتفظ بالنسخة القديمة كنسخة احتياطية.
2) افتح المجلد الذي يحتوي على app.py و requirements.txt.
3) اضغط على شريط عنوان المجلد في File Explorer، اكتب cmd ثم اضغط Enter.
4) نفّذ كل أمر لوحده، واضغط Enter بعده:

   py -m venv venv
   venv\Scripts\activate
   py -m pip install -r requirements.txt

5) أنشئ ملف الإعدادات لأول مرة فقط:

   copy .env.example .env

   إذا كان ملف .env موجودًا بالفعل، لا تستبدله. افتحه وعدّل الإعدادات المطلوبة.
   غيّر ADMIN_EMAIL و ADMIN_PASSWORD إلى بيانات جديدة قوية، وغيّر SECRET_KEY
   إلى قيمة عشوائية طويلة (32 حرفًا على الأقل). لا ترسل كلمة السر في المحادثات
   ولا ترفع ملف .env إلى الإنترنت أو تشاركه مع المشتري.

6) شغّل المتجر:

   py app.py

7) افتح Chrome واكتب:

   http://127.0.0.1:5000

لو ظهر خطأ، انسخ رسالة الخطأ كاملة أو أرسل صورة واضحة لها. لا تكتب أوامر متعددة
في سطر واحد. لإيقاف الخادم اضغط Ctrl+C داخل نافذة CMD.

ملاحظات مهمة:
- هذا يشغّل الموقع محليًا على جهازك فقط؛ ليس نشرًا عامًا على الإنترنت.
- يجب تثبيت Python ووجود اتصال بالإنترنت لتنزيل المكتبات أول مرة.
- لم يتم تضمين ملف .env أو بيانات دخول المسؤول في هذه الحزمة.
- اختبارات Flask لم تُشغّل في بيئة التجهيز لأن مكتبات Flask غير متوفرة هنا،
  لكن تم فحص صياغة JavaScript وPython وJinja وقواعد CSS.
